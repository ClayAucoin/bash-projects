# These are some small bash helper programs.

- [Combine Files](https://github.com/ClayAucoin/bash-projects/tree/main/bash-combine-files)
  - `combine` is a Bash script that combines the contents of all files with specified extensions in the current directory (and its subdirectories) into one single text file. It is designed to be run from **Git Bash** on Windows.
- [bash-list-proj](https://github.com/ClayAucoin/bash-projects/tree/main/bash-dir-list-proj)
  - `proj` is a small helper function you can add to your `~/.bashrc` that lets you quickly jump into any sub-project in the current directory and optionally run common actions like opening the folder in VS Code or checking git status.
- [bash-new-project](https://github.com/ClayAucoin/bash-projects/tree/main/bash-new-project)
  - This script creates a new project folder structure inside your `~/projects` directory. It sets up common web project files, directories, and boilerplates automatically.
